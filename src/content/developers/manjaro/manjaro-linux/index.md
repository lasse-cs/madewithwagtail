Manjaro is a free and open source Linux operating system that emphasizes user privacy and control of their hardware. It is user-friendly and suitable for those new to computers, and can be installed on a wide range of devices.. Architectures supported include x86-64 and ARM. Manjaro provides numerous customization options and applications, as well as security and privacy features. It also offers several graphical user interfaces.
