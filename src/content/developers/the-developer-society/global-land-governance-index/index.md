Landex is a global land governance data platform created with the International Land Coalition to help make land data more accessible, understandable and useful for organisations, researchers and advocates around the world. This project mattered because the data is complex, but the goal was to make it clear, visual and usable so it could support real change.

We worked with ILC to design the Landex platform and digital brand, building interactive tools that allow users to explore the global index, view country data, submit data and understand land governance through visualisations and storytelling. The platform brings together multiple datasets and presents them in a way that supports research, advocacy and decision making.

Wagtail was a fantastic fit for this project because it allowed us to combine a content-managed website with a complex data platform, giving the team flexibility while keeping the platform maintainable long term.
