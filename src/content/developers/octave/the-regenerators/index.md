The Regenerators are an impact organisation dedicated to producing content that informs and inspires communities to take action to regenerate and heal the planet.

Design
The overarching goal was to design a website that literally felt alive and regenerative. We also needed to create excitement, hope, and engage people with the important information and action steps. We achieved this through using rich visual imagery of plants and animals. We combined this imagery with careful layering to create beautiful foliage scenes that appear to be growing around, out of, and behind interface components. Equally important, we designed a system of reusable and responsive content blocks. These allow the team to build pages around their content and needs. We designed these content blocks to have the ability to be visually themed to support content using bits of regenerative foliage to add another layer of visual customisation to the platform.

The Build
The main feature for user engagement is the action planner. Here a user can build a profile that can then recommend regenerative actions based on their interests and availability. Much of the site’s content is taggable in a way that allows the action planner to categorise it, and work out the best recommendations for a user profile.The site is built with Wagtail CMS. We used a strong page builder approach to data modelling pages by creating a library of reusable “streamfield” blocks. These provide a flexible but consistent content management experience across all areas of the site.We also built the capability for the team to build integrated microsites for the promotion of movies. They've already used this feature to promote their latest release 'Regenerating Australia'.
